# AgileX Ranger Mini 3.0 모델

논문의 시뮬레이션에서 착륙 패드를 싣고 가는 지상 차량(UGV)의 외형 모델이다.

- `source/`는 AgileX Robotics의 공개 저장소 [`ugv_gazebo_sim`](https://github.com/agilexrobotics/ugv_gazebo_sim) commit `27633a956c845903ee630538afeb17fe70afdd84`에서 변경 없이 복사한 `ranger_mini_v3` package이다.
- upstream `package.xml`은 라이선스를 BSD로 선언한다. `ranger_base.zip`은 upstream `ranger_base.dae` 압축본이다.
- Isaac Sim USD는 `./scripts/import_ranger_mini_v3.sh`로 만든다.
